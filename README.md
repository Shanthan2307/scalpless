# Scalpless — one human, one fair chance

Scalpless is a fair-launch protocol for hype products: every World ID-verified human gets exactly one
entry, winners are drawn with Sui's on-chain randomness, and each win is a tokenized, non-transferable
claim on a real unit of inventory — paid in full, in layaway, or with an uncollateralized
"borrow on yourself" loan, resold at no more than 110% of face value, and redeemed for delivery.

Monorepo:

- `packages/sui-contracts` — Sui Move package
- `apps/backend` — World ID / AgentKit verification, attestation oracle, underwriting
- `apps/web` — Next.js app
